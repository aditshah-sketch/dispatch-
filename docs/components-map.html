The system

Left to right is the week: collect, draft, review, approve, deliver. Everything persists in one Postgres database, and a scheduler queues each step at its time.

One week, in order

Times are India Standard Time. On Vercel's free plan each step can start up to an hour late.

  1. Mon–Wed · 08:00CollectFeeds and searches stored once; same-event coverage grouped; last four editions excluded.
  2. Wed · 15:00DraftGemini scores candidates, picks 8–10 across 3+ topics and writes 2–3 sentences each.
  3. Wed · 18:00ReviewDraft arrives in Telegram with Approve, Edit and Swap on every story.
  4. Wed · 22:00Reminder if unconfirmedA nudge, once. Silence never sends anything.
  5. Thu · 09:00DeliverSends the approved snapshot only. No approval, no email.

Edition states

The edition moves forward only through these steps. Any edit after approval sends it back to review.
